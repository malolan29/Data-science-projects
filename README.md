# Zomato Restaurant Recommendation System

data link : https://www.kaggle.com/datasets/rabhar/zomato-restaurants-in-india/data

A simple content-based recommendation project using Chennai restaurant data from Zomato.

- Loads and explores the restaurant dataset.
- Filters the data to restaurants in Chennai.
- Cleans and prepares features such as cuisine, establishment type, locality, and cost.
- Uses weighted rating to balance popularity and quality.
- Builds a cosine similarity model to recommend similar restaurants.
- Supports recommendations by restaurant name, locality, or both.

Tech stack:
- Python
- Pandas
- NumPy
- scikit-learn
- Matplotlib
- Seaborn
- Plotly

Notebook:
- Zomato_rec_sys.ipynb
